# Ikonex Frontend

React dashboard for Ikonex Academy's Student Management System.

## Stack

- React with Vite
- TypeScript
- Tailwind CSS
- TanStack Query
- Axios
- Lucide React
- Recharts
- Sonner
- React PDF

## Setup

```bash
npm install
copy .env.example .env
npm run dev
```

## Environment

```env
VITE_API_URL=http://localhost:3000
```

## Build

```bash
npm run build
```
